# Pitfall Shooting Gallery

Author: Jose Lima

Design: This is a classic shooting gallery game. Howeverin this version, if you miss your shot then 
        you will get shot. Aim carefully and hit all targets to win the game. 

Screen Shot:

![Screen Shot](scenes/demo_screenshot.png)

How To Play:

Controls:

* Mousepad to use the camera.
* enter/return to shoot a ball

Goals/Strategies:
* Hit all targets to win!
* Aim carefully, if you miss you will get shot by the cannon and lose a health point. 

This game was built with [NEST](NEST.md).
